# Harmony passages: places where whole sections of books run in parallel. Read by lib/bible/harmony.js.
#
# One row per line: two or more members joined by "=", each a book and the verses it spends on the
# passage. A row's members are matched verse by verse, in order, when they have the same number of
# verses; when they differ, each verse of one is matched with the whole of the other. So a row is cut
# wherever the books drift apart, and a stretch with no counterpart is left out. A member may be several
# pieces ("Ps 106:1, 47-48"). A row that starts with "~" is matched that way whatever its lengths. The main member is the
# first canonically, except that Psalms is main against any book that reproduces it.
#
# English (ESV) verse numbering, as everywhere on the site. Rows are kept in canonical order of the main
# member, a section at a time.
